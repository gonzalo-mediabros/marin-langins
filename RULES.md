# RULES

- Web 100% estática. se exporta para subir a un hosting web tradicional.
- Se respeta el texto tal cual envió el cliente. no se inveta información
- No se omite información, no se es proactivo en la generacion de texto.

## Lo que NO hacer en este proyecto

- No usar npm — siempre pnpm
- inventar textos o cambiar los textos enviados por el cliente
- No hardcodear colores fuera de @theme
- No crear componentes parametrizados de página completa (ver filosofía en Astro-Builder)
- No agregar dependencias sin consultar
